# Book Tracker Overview 
The Book Tracker is a special tracker that any book worm can use to save their favorite books, regardless of what book it may be. The tracker helps book lovers due to its functions like saving books they've read, looking at the past books they've saved, as well as a filter to have more precise book saving. Currently, the book tracker can only sasve books and print those books out to the user but has many future plans and improvments to be made. 

## Uses
### Current Fuctions
- Saving Books
- Viewing Saved Books
- Stop Program Option
- User Interaction system 
- Feedback Feature 

### Future Functions
- Book wishlist
- Book recomendation section
- Book Shop Reccomendations
- Filtered Saved Book Libarary(Favorites, Scary, Seasonal, etc.)

## Tools
- Data structures/containers (Vector)
- Loops
- Class
- Chrono w- algorithim
- conditionals (if else, switch statements)
- Fstream (read/write)


## Instructions
1. User selections options of what the program can do from menu. (Saving, Viewing, Stopping, etc)
2. User interacts with mode that was selected (Guidance on what to do within program will be given)
3. User is sent to the menu again and user chooses what they will do, wether to contintue or stop the program is up to the user.
